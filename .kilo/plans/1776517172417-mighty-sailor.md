# Plan: Add Horizontal Scroll Animation to InfoBar

## Goal
Add a slow left-to-right marquee animation to the InfoBar component (like airport departure boards).

## Approach
Use CSS keyframes animation with infinite scroll, similar to a marquee effect.

## Changes Required

### 1. Modify `components/navigation/info-bar.tsx`
- Replace the current flex layout with an animated container
- Add CSS keyframes for the scroll animation
- Wrap items in a scrolling container that moves continuously

**Options to consider:**
1. **Simple marquee** - All items scroll together in a continuous loop (smooth but items disappear then reappear)
2. **Duplicated content marquee** - Duplicate the items so there's always content visible during scroll

**Recommended:** Option 2 for a smoother effect where content never disappears.

### 2. Styling approach
- Use Tailwind CSS (project uses Tailwind v4 per AGENTS.md)
- Add animation keyframes via inline styles or Tailwind config
- Set animation duration to ~15-20 seconds for "slow" effect

## Implementation Notes
- The current `hasDarkHero` and `isScrolled` theme logic should be preserved
- Ensure responsive behavior still works (hidden on mobile is already handled via `hidden sm:inline`)
- Test that the animation works with the backdrop blur effect
